# Ariadne Atlas - pointer layer

**Ariadne Window is the live control surface. Ariadne Atlas is the external knowledge map and evidence index.**

This `context/atlas/` folder is the **small, stable, raw-URL pointer layer**
for Web AI. It contains pointers + JSONL indexes only - **no handoff zips, no
bulk run folders, no secrets, no DB/CAD/binaries**. Bulk evidence (handoff
zips, full reports) lives in the Google Drive `Ariadne Atlas` archive.

1. Ariadne Window `/state/current` (live): https://ariadne-window.paulseongminpark.workers.dev

3. `CURRENT_STATE.md` - snapshot counts + Window safety facts.
