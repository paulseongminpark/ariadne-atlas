## What Belongs Here

- compact routing documents
- current operating-state summaries
- JSONL indexes for runs, handoffs, reports, contracts, and Window materialized state
- no archives, live DB files, binaries, CAD/BIM files, or bulk run folders

Bulk evidence lives in GDrive Atlas. This repo points to evidence; it does not contain the evidence archive.
